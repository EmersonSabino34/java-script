# 📘 Aula 01 — Introdução ao HTML, CSS e JavaScript
Projeto educacional desenvolvido para **introdução à manipulação do DOM**, uso básico de **HTML**, **CSS** e **JavaScript puro**, ideal para iniciantes em desenvolvimento web.

---

## 🎯 Objetivo do Projeto

Este projeto tem como objetivo ensinar, de forma prática:

* Estrutura básica de um documento HTML
* Estilização simples com CSS
* Seleção de elementos no DOM
* Uso de variáveis em JavaScript
* Eventos de clique
* Manipulação de texto e estilos via JavaScript

Tudo isso utilizando **apenas tecnologias nativas da web**, sem frameworks.

---

## 🧪 Tecnologias Utilizadas

* **HTML5** — Estrutura da página
* **CSS3** — Estilização básica e layout
* **JavaScript (Vanilla JS)** — Interatividade e lógica

---

## 🖥️ Funcionalidades

* Alteração dinâmica de texto ao clicar nos elementos
* Mudança de estilos via JavaScript
* Exibição de mensagens com `alert()`
* Exemplo de cálculo matemático
* Uso do `console.log()` para depuração

---

📁 aula-01

## ▶️ Como Executar

1. Faça o download ou clone do repositório
2. Abra o arquivo `index.html` no navegador
3. Abra o **DevTools (F12)** para visualizar o console

Não é necessário instalar dependências.
